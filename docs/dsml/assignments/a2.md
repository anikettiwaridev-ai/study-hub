Write Python code to (a) check null or missing values in a DataFrame, (b) fill null values with 0 or the mean, (c) drop rows that have null values.

- Marks and Age were integers; after one NaN each they print as **floats** (85.0, 20.0), because NaN is a float.
- `isnull().sum()` counts per column (the axis rule: summing down the rows).
- Filling Marks with **0** is wrong: 0 is a real (failing) mark. The mean (80.0) keeps the column's average. 0 is only right when it is a meaningful default, such as a count.
- `fillna({"Marks": ...})` fills only that column, so Age still has its NaN.
- `dropna()` removes every row with **any** NaN: two of six rows gone.
