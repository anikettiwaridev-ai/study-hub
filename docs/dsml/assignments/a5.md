Each row is [P(class 0), P(class 1)] and sums to 1. `predict` is simply `predict_proba[:, 1] ≥ 0.5`. Row 3 (p = 0.6284) is predicted 1 but is actually 0: a false positive. With a threshold of 0.7 it would be right, and nothing about the model would change. The threshold is a choice, and moving it trades precision against recall; the ROC curve shows every choice at once ([Unit 3](../notes/unit-3#roc)).

sklearn puts class 0 first, so the matrix reads **[[TN, FP], [FN, TP]]** = [[48, 3], [10, 19]]. By hand for class 1: precision = 19/(19 + 3) = 0.864, recall = 19/(19 + 10) = 0.655, F1 = 2 × 0.864 × 0.655/(0.864 + 0.655) = 0.745, accuracy = (48 + 19)/80 = 0.8375.

**What the accuracy hides:** 84% sounds good, but recall 0.66 means the model misses 10 of the 29 real buyers, and always predicting "no" would already score 51/80 = 64%. On imbalanced data, report the per-class numbers.
