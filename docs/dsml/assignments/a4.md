::: danger Two leaks a viva may ask about
- **The scalers were fitted before the split** (Q7 comes before Q9 on the sheet). The correct order is split first, then `fit_transform` on the training set and `transform` on the test set; Assignment 5 does it that way.
- **Target leakage:** y = `Senior` is computed from `Experience`, and `Experience` is still in X. Any model would score 100% by learning "Experience ≥ 10" and would have learned nothing. Here nothing is trained, so no harm is done, but say this if asked.
- And X uses the label-encoded `Department_LE`, so the invented HR < IT < Sales order goes into the features; the one-hot version would be the right choice.
:::
