<Q id="A4.Q3">

Write a C++ program to create suitable Point and Circle classes with private data members. Using friend functions where appropriate, determine whether a point lies inside a circle and whether two circles intersect. Validate all dimensions before performing calculations.

::::: details Solution

::: code-group
<<< @/../code/oop/assignments/a4-q3.cpp [Program]
<<< @/../code/oop/assignments/a4-q3.out{txt} [Output]
:::

- `isInside` needs private data from **both** a `Point` and a `Circle`, so it is declared a friend in **both** classes. `class Circle;` at the top is the forward declaration that lets `Point` mention `Circle` before it is defined.
- A point is inside when its distance from the centre is at most the radius: (3, 4) is exactly 5 from the origin, so it is on the edge and counts.

- Validation: a non-positive radius is rejected in the constructor, before any calculation can use it.

The two `.cpp` files are compiled separately and then **linked** together. Both include `Geometry.h`, so both contain every function definition.

**What stops "multiple definition" errors is `inline`, not the include guard.** A guard only works *within one file*. Each `.cpp` file is compiled on its own, so each gets its own copy of the definitions. Without `inline`, the linker then finds `squareArea` defined twice and refuses:
