<Q id="A2.Q3">

Write a menu-driven C++ program that repeatedly displays a menu and performs the selected computation until the user selects Exit: (i) factorial, (ii) prime check, (iii) reverse and palindrome check, (iv) Armstrong number, (v) perfect number, (vi) GCD and LCM, (vii) sum and count of primes between L and R, (viii) first N Fibonacci terms and their sum, (ix) strong number, (x) exit.

::::: details Solution

::: code-group
<<< @/../code/oop/assignments/a2-q3.cpp [Program]
<<< @/../code/oop/assignments/a2-q3.in{txt} [Input]
<<< @/../code/oop/assignments/a2-q3.out{txt} [Output]
:::

The menu is a `do { ... } while (choice != 10);` loop around a `switch`. `do-while` fits because the menu must show **at least once**. Each option is one small function.

| Option | Idea |
|---|---|
| Factorial | multiply 2 × 3 × … × n; start from 1 |
| Prime | no divisor from 2 up to √n (`i * i <= n`) |
| Palindrome | build the reverse digit by digit (`n % 10`, `n / 10`) and compare |
| Armstrong | sum of each digit raised to the number of digits equals n (153 = 1³ + 5³ + 3³) |
| Perfect | sum of proper divisors equals n (28 = 1 + 2 + 4 + 7 + 14) |
| GCD / LCM | Euclid: replace (a, b) with (b, a % b) until b is 0; LCM = a / GCD × b |
| Strong | sum of factorials of the digits equals n (145 = 1! + 4! + 5!) |

The Input tab runs every option once, then 10 to exit; the Output tab is that whole session, menu included.

::: danger Two classic `switch` errors
A `case` without `break` falls through into the next case. A variable declared inside a `case` needs its own `{ }` block (see options 7 and 8), or the compiler complains that the jump to a later `case` skips its initialisation.
:::

:::::

</Q>

`continue` skips the **rest of this iteration** and goes to the next number; `break` leaves the **whole loop**. The `break` test is placed first, so 75 (which is also divisible by 3) stops the loop rather than being skipped; either way it is not printed, and nothing after it is.

<Q id="A2.Q8">

Write a menu-driven C++ program to print different complex pyramid patterns based on the user's choice, repeating until Exit: (i) palindromic number pyramid, (ii) alphabetic palindromic pyramid, (iii) hollow number pyramid, (iv) inverted number pyramid, (v) diamond number pattern, (vi) hollow diamond, (vii) exit.

::::: details Solution

::: code-group
<<< @/../code/oop/assignments/a2-q8.cpp [Program]
<<< @/../code/oop/assignments/a2-q8.in{txt} [Input]
<<< @/../code/oop/assignments/a2-q8.out{txt} [Output]
:::

Every pattern is solved the same way: for row `i`, work out **(1) how many leading spaces** and **(2) what is printed after them**, as formulas in `i` and `N`.

| Pattern | Leading spaces in row i | Then print |
|---|---|---|
| Palindromic pyramid | 2(N − i) | i … 2 1 2 … i |
| Alphabetic | 2(N − i) | the same with letters: `char('A' + k - 1)` |
| Hollow pyramid | N − i | 1, then 2i − 3 spaces, then 1 (first row: one 1; last row: 2N − 1 ones) |
| Inverted | 2(i − 1) | i, i + 1, …, N |
| Diamond | 2(N − i) | the palindromic row for i = 1 … N, then N − 1 … 1 |
| Hollow diamond | 2(N − i) | `*`, then 4(i − 1) − 1 spaces, then `*` (row 1: one `*`) |

Every output above matches the figures in the assignment exactly.

::: danger The Python habit
`cout << "*" * i;` does not repeat a string in C++; it does not even compile. Use a loop.
:::

:::::

</Q>
