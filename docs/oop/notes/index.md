# Notes

Units 1 to 4, the whole mid-semester syllabus. They are built from the lecture notes up to 14 September (the v2 revision), the later lecture notes for static members, friends and Unit 4, and what no notes covered: type conversion, `<<` and `>>`, which operators cannot be overloaded, and the pitfalls of overloading. Mistakes in the handwritten notes have been corrected without comment, and every output shown comes from running the program.

| Unit | Covers | Weight in past mid-semester papers |
|---|---|---|
| [1 · OOP concepts](./unit-1) | Abstraction, encapsulation, information hiding, signatures, polymorphism, inheritance | The 2 to 3 mark opener, every paper |
| [2 · Programming basics](./unit-2) | Storage and scope, operators, comma, precedence, casting, functions, passing, defaults, overloading, arrays, dynamic memory | Output traces in every paper and quiz |
| [3 · Classes and objects](./unit-3) | Member functions, `this`, static members, `const`/`constexpr`, memory and padding, friends, every constructor, copying, destructors | The long class question |
| [4 · Operator overloading and conversions](./unit-4) | Unary, binary, `++`, `=`, `<<` `>>`, non-overloadable operators, conversions, pitfalls | Operator questions and the 4-mark conversion question |

::: tip Two ways to use the notes
**Before a quiz:** read the red **Trap** boxes and do the **Quick check** at the end of each unit. Or switch on **Traps only** in the top bar, which hides everything except the traps.

**Before the mid-semester:** read each unit fully, then attempt the papers with solutions hidden. The notes explain *why*; the papers show how she asks.
:::
