# How often questions repeat

Every appearance of every topic across the six mid-semester papers, the two end-semester papers, all eleven quizzes, the three practice sheets and the mock paper.

- **⟳ Exact**: the same question word for word.
- **≈ Reworded**: the same question in different words (or the same function as fill-in-the-blanks).
- **Δ Variant**: the same structure with different data.
