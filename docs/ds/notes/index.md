# Notes

Units 1 to 5, the whole mid-semester syllabus, written in the format of the Stacks & Queues quiz-prep sheet. Each unit opens with a **toolkit table**, then one numbered section per idea: the method, a worked example traced step by step, the rule in one line, the traps, and the code with the <span class="hl-legend">likely lab-quiz blanks highlighted</span>. Each unit ends with a traps table, a checklist and a **Quick check** that marks itself.

They are built from the lecture slides, the three practice sheets, every past paper and every quiz. Where the slides are wrong (a broken polynomial algorithm, a double `delete`, a mislabelled `deleteNode`), the notes say so. Every program output shown comes from compiling and running the program.

| Unit | Covers | Weight in the six past mid-semester papers |
|---|---|---|
| [1 · Complexity, recursion, pointers](./unit-1) | Loop counting, space, notation, recurrences by substitution, the master theorem, binary and **biased** search, pointers, classes, memory arithmetic | A recurrence in 5 of 6 papers; Biased Search in 2, including the latest |
| [2 · Linked lists](./unit-2) | Singly, doubly, circular; the function bank; recursive traces; polynomials; sparse matrices; lists vs arrays | Every paper: one or two functions to write |
| [3 · Stacks and expressions](./unit-3) | All six conversions, both evaluations, MCQ tricks; array and linked stacks; max/min-stack; brackets; pop orders; recursion | Every paper: an expression question, 5–6 marks |
| [4 · Queues](./unit-4) | Conventions; linear, circular, linked queues; deques; priority queues; scheduling; ring buffer | Every paper: a trace or a queue program |
| [5 · Trees](./unit-5) | Terminology, representations, types and formulas, BFS and DFS, building from traversals, counting, recursive tree code | New to the mid-semester this year |

::: tip Two ways to use the notes
**Before the mid-semester:** read each unit fully, then do the [papers](../papers/) with solutions hidden. The worked examples here use different data from the papers, so the papers stay fresh.

**Before a quiz:** read the trap boxes and do the Quick check in each unit, or switch on **Traps only** in the top bar. Then read [Beat the 10-minute clock](../quiz-clock).
:::
