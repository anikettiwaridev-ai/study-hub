In the given LinkedList class, fill in the blanks such that the function x(int val, int key) inserts a new node with value 'val' before the first occurrence of key in the linked list. Handle edge cases when the list is empty or the key is at the head.

```cpp
class LinkedList {
public:
    Node* head = NULL;
    void x(int val, int key) {
        Node* n = new Node(val);
        if (!head) return;
        if (head->data == key)
            { n->next = ___(1)___;
              head = ___(2)___;
              return; }
        Node* t = head;
        while (t->next && ___(3)___ != key)
            t = t->next;
        if (!t->next) return;
        n->next = t->next;
        t->next = n;
    } };
```

<FillIn q="Blank (1):" answer="head">

The key is at the head: the new node goes in front of it.

</FillIn>

<FillIn q="Blank (2):" answer="n">

…and becomes the head.

</FillIn>

<FillIn q="Blank (3):" answer="t->next->data">

To insert **before** the key you must stop on the node **before** it, so test the next node's data. The scanned sheet wrote `t->data`, which stops on the key node itself and inserts after it: the blank is compared with `key`, so it is an int, but it must be the **next** node's int.

</FillIn>

</Q>
