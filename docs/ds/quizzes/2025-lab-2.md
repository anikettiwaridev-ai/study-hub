Complete the following recursive function that counts the total number of leaf nodes in a binary tree.

```cpp

```

<FillIn q="Blank (1):" answer="1">

A leaf counts as one.

</FillIn>

<FillIn q="Blanks (2) and (3), as `x, y`:" answer="root->left, root->right|root->left,root->right">

</Q>

<Q id="LA2.Q2">

The following recursive function is supposed to compute the height of a binary tree (i.e., the number of edges on the longest path from the root to a leaf):

```cpp
int findHeight(Node* root) {
    if (root == nullptr)
        return -1;
    else {
        int lHeight = findHeight(root->left);
        int rHeight = findHeight(root->right);
        return ___(1)___;
    }
}
```

<FillIn q="Blank (1):" answer="1 + max(lHeight, rHeight)|1+max(lHeight,rHeight)|max(lHeight, rHeight) + 1|max(lHeight,rHeight)+1|1 + max(lHeight,rHeight)">

One edge to the taller child. The `return -1` for an empty tree is what makes a leaf's height 0.

</FillIn>

</Q>

<Q id="LA2.Q3">

Complete the function rightRotate(), which performs a Right Rotation on an unbalanced node y in an AVL tree and returns the new root of the rotated subtree.

```cpp
Node* rightRotate(Node* y) {
    Node* x = y->left;
    Node* z = x->right;
    x->right = ___(1)___;
    y->left = ___(2)___;

    x->height = 1 + max(getHeight(x->left), getHeight(x->right));

```

<FillIn q="Blank (1):" answer="y">

x moves up; y becomes x's right child.

</FillIn>

<FillIn q="Blank (2):" answer="z">

</FillIn>

x is the new root of this subtree. (Heights: y first, because x's height depends on y's.)

</FillIn>

</Q>

<Q id="LA2.Q4">

Complete the following function that finds the minimum value node in a BST.


<Q id="LA2.Q5">

Let T be a rooted BST storing integer keys. The Lowest Common Ancestor (LCA) of two nodes n1 and n2 is defined as the lowest node in T that has both n1 and n2 as descendants (a node can be a descendant of itself). Complete the function below which returns the LCA of two nodes n1 and n2 in a BST.

```cpp
Node* LCA(Node* root, int n1, int n2) {
    if (root == nullptr)
        return nullptr;
    if (root->data > n1 && root->data > n2)
        return LCA(___(1)___);
    if (root->data < n1 && root->data < n2)
        return LCA(___(2)___);
    return root;
}
```

<FillIn q="Blank (1):" answer="root->left, n1, n2|root->left,n1,n2">

Both keys are smaller than root: the LCA is in the left subtree.

</FillIn>

<FillIn q="Blank (2):" answer="root->right, n1, n2|root->right,n1,n2">

Both larger: go right. Otherwise they split here (or one equals root), so root is the LCA.

</FillIn>

</Q>
