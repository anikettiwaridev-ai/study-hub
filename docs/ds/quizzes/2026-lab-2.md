<Q id="LT2.Q1">

Priority Queue (PQ) is defined as a queue where DEQUEUE operation deletes highest priority element from the queue. If two or more highest priority elements are present then FIFO is followed while deleting elements. Assume a priority queue is implemented using a sorted linked list arranged in descending sorted order. The ENQUEUE(priority, val) operation inserts the new element in the sorted linked list such that the next element to be deleted is in the beginning of the sorted linked list. Complete the function ENQUEUE below that returns the updated head pointer. Use the options below to fill in the blanks.

Options: i. `head`  ii. `head -> next`  iii. `head -> val`  iv. `temp`  v. `temp -> next`  vi. `temp -> val`  vii. `newNode`  viii. `newNode -> next`  ix. `newNode -> val`

```cpp
Node * ENQUEUE (Node* head, int priority, int data) {
    Node* newNode = new Node (priority, data);
    Node* temp = head;
    if (temp == NULL)
        return ___(1)___;
    if (temp -> key < priority) {
        newNode -> next = ___(2)___;
        return ___(3)___;
    }
    while ((temp -> next != NULL) && (temp -> next -> key >= priority))
        temp = temp -> next;
    ___(4)___ = temp -> next;
    temp -> next = ___(5)___;
    return ___(6)___;
}
```

<FillIn q="Blank (1):" answer="newNode|vii">

Empty queue: the new node is the whole list, and it is the head to return.

</FillIn>

<FillIn q="Blank (2):" answer="temp|head|iv|i">

The new node has the highest priority, so it goes **in front of** the current head (`temp` and `head` are the same node here).

</FillIn>

<FillIn q="Blank (3):" answer="newNode|vii">

It is the new head.

</FillIn>

<FillIn q="Blank (4):" answer="newNode->next|newNode -> next|viii">

The left side of an assignment receiving `temp->next` (a `Node*`): link the new node to the rest first.

</FillIn>

<FillIn q="Blank (5):" answer="newNode|vii">

Then hook the new node in after temp. The order of blanks 4 and 5 is the order that never loses the rest of the list.

</FillIn>

<FillIn q="Blank (6):" answer="head|i">

The head did not change in this case, so return it.

</FillIn>

::: tip Why `>=` in the while (and `<` in the if)
Walking past nodes with priority **≥** the new one puts the new node **behind** earlier equal priorities: FIFO among equals, as the question demands. The `if (temp->key < priority)` takes the head position only on **strictly** higher priority, for the same reason.
:::

<Q id="LT2.Q2">

Consider a modified stack is implemented using linked list. The modified stack supports maxElement function apart from fundamental operations like push, pop, tos, isEmpty, isFull etc. The function maxElement returns the maximum element present in the stack in O(1) time complexity. To support maxElement function, node of the stack stores the current maximum along with the data in each node. Current maximum in a newly pushed node would be the maximum of data to be pushed and maximum stored in the node at top of the stack. The 'key' variable in a node stores the maximum while 'val' stores the data. Complete the modified push function below that allows maxElement in constant time. The push function returns the updated head. Use the options below to fill in the blanks.

Options: i. `head`  ii. `head -> next`  iii. `head -> val`  iv. `newNode`  v. `newNode -> next`  vi. `newNode -> val`  vii. `data`  viii. `head -> key`  ix. `newNode -> key`

```cpp
Node* push (Node* head, int data) {
    Node* newNode;
    if (head == NULL) {
        newNode = new Node (data, data);
        return newNode;
    }
    if (head -> key > data)
        newNode = new Node (head -> key, data);
    else
        newNode = new Node (___(1)___, ___(2)___);
    newNode -> next = ___(3)___;
    return ___(4)___;
}
```

<FillIn q="Blanks (1) and (2), as `x, y`:" answer="data, data|data,data|vii, vii|vii,vii">

The constructor is `Node(key, val)` = (maximum, data). In the `else` branch the new data is at least the old maximum, so it **is** the new maximum: `Node(data, data)`, exactly like the empty-stack case two lines above.

</FillIn>

<FillIn q="Blank (3):" answer="head|i">

Push at the head of the list: the new node points at the old top.

</FillIn>

<FillIn q="Blank (4):" answer="newNode|iv">

The new node is the new top.

</FillIn>
