Consider the following function 'fun' that recursively prints binary strings of length 'n' which are divisible by 3 in descending order. The function takes default arguments 'curr': an empty string and 'rmdr': remainder so far, initially set to 0.

```cpp
void fun(int n, string curr = "", int rmdr = 0) {
    if (curr.length() == n) {
        if (rmdr == ___(1)___) {
            cout << curr << endl;
        }
        return;
    }
    fun(n, curr + '1', (rmdr*2 + 1) % 3);
    fun(n, ___(2)___, ___(3)___);
}
```

<FillIn q="Blank (1):" answer="0">

Divisible by 3 means the remainder is 0.

</FillIn>

<FillIn q="Blank (2):" answer="curr + '0'|curr+'0'|curr + &quot;0&quot;|curr+&quot;0&quot;">

The given call appends `'1'`; the other branch appends `'0'`. Calling '1' first is what makes the output descending.

</FillIn>

<FillIn q="Blank (3):" answer="(rmdr*2) % 3|(rmdr * 2) % 3|rmdr*2%3|(2*rmdr)%3|(rmdr*2)%3|(2 * rmdr) % 3">

Appending a bit b to a binary number doubles it and adds b. So the new remainder is (rmdr × 2 + b) % 3. The given call shows b = 1; here b = 0: `(rmdr*2) % 3`. Copy the pattern of the line above and change the one thing that differs.

</FillIn>

<Q id="LT1.Q2">

Assume p is a pointer pointing to a node in a singly linked list, which is not the last node. Complete the code below so that the data stored in node pointed by p is removed from the linked list.

```cpp
void erase(Node* p) {
    Node* temp = ___(1)___;
    p->data = ___(2)___;
    p->next = ___(3)___;
    delete temp;
}
```

<FillIn q="Blank (1):" answer="p->next">

`temp` is a `Node*`, and it is the node that will be deleted. Without the head you can't reach p's predecessor, so the trick is to delete the **next** node instead.

</FillIn>

<FillIn q="Blank (2):" answer="temp->data|p->next->data">

Copy the next node's value into p: p now "is" the next node.

</FillIn>

<FillIn q="Blank (3):" answer="temp->next|p->next->next">

Skip over temp. Then `delete temp` frees the node whose data you already copied. This is why the question says p is not the last node: there would be no next node to copy.

</FillIn>

<Q id="LT1.Q3">

Complete the function secondLargest() so that it returns a pointer to the node containing the second largest distinct value in a non-empty singly linked list. Assume that the list contains at least two distinct values. The function takes the address of first node of the linked list as input.

```cpp
Node* secondLargest(Node * head) {
    Node* F = nullptr;
    Node* S = nullptr;
    Node * T;
    for (T = head; T; T = T->next) {
        if (!F || T->data > F->data) {
            S = ___(1)___;
            F = ___(2)___;
        }
        else if ((T->data < F->data) &&
                 (!S || T->data > ___(3)___))
        {
            S = ___(4)___;
        }
    }
    return S;
}
```

<FillIn q="Blank (1):" answer="F">

A new largest value arrives: the **old** largest becomes the second largest. It must be written before F changes.

</FillIn>

<FillIn q="Blank (2):" answer="T">

T is the new largest. `S` and `F` are `Node*`, so these blanks are pointers (`F`, `T`), never `->data`.

</FillIn>

<FillIn q="Blank (3):" answer="S->data">

Compared with `T->data` (an int), so this blank must be an int: `S->data`. `!S ||` protects it from a NULL S.

</FillIn>

<FillIn q="Blank (4):" answer="T">

T is smaller than the largest but bigger than the current second: it becomes the second. `T->data < F->data` (strictly) is what makes it the second largest **distinct** value; a copy of the maximum is skipped.

</FillIn>
